Disk Growth Monitor 1.3.0 - Windows x64

Private Python/Qt runtime is bundled under .venv.
No global Python, pip, System PATH, Task Scheduler job or Windows Service is installed.
Choose an empty folder, preferably on D: to avoid consuming C: space.
The editable source folder must not be overwritten by this installer.

GUI: DiskGrowthMonitor.exe
CLI: dgm.exe --help
The GUI requests Windows UAC administrator approval at every unelevated launch.
This installer also requires UAC administrator approval.
Headless CLI/background jobs retain explicit per-operation privilege checks.

WizTree is proprietary and NOT included. Select your installed WizTree executable
in the System tab. WinDirStat/gdu can be downloaded explicitly into .venv/tools.
No scan, cleanup or automatic task starts during installation.

Upgrades preserve data and logs. Close the application before upgrading.
For app-assisted updates, the app downloads the official Release, checks SHA-256,
backs up config/history and temporarily disables/stops only its own runner.
The runner registration is retained and its original state is restored afterward.
One Update button runs the full download/install workflow. An observer started
before elevation reopens the app in the original user session after verification.
Manual upgrades require a disabled/stopped runner; legacy builds may need it removed.
Updates started from source use a managed .dgm-app runtime inside the current app
folder and keep the existing data/log home. The same launcher opens the new app.
Source code and its development .venv are retained.
Before uninstalling, stop scans and remove any Task/Service using the application.
Uninstall preserves scan history, logs and tools downloaded after installation.
Review retained files yourself; the uninstaller does not erase the whole folder.

This build is not code-signed. Windows may show an unknown-publisher/SmartScreen warning.
Only run installers from the official project Release. Compare SHA256SUMS.txt.

Portable mode: installer.exe /PORTABLE=1
This skips Start menu/Desktop shortcuts and the Add/Remove Programs entry.
It still includes an uninstaller, which preserves user-created data and logs.
